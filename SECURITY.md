# Security

Report a vulnerability through
[private vulnerability reporting](https://github.com/SilentBless/wire-repr-rs/security/advisories/new).
Do not open a public issue.

In scope: memory unsafety reachable through the safe public API or derived code, a view that
exposes bytes outside its framed range, and a panic or unbounded loop on untrusted input.

The latest `1.x` release receives fixes.
